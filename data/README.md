# data/

Dieser Ordner ist **nicht** für persistente Browser-Weltdaten oder Datenbank-Dumps vorgesehen.

- Testdaten und Fixtures: `tests/fixtures/`
- Checkpoint-Nachweise: `evidence/`
- Maschinenlesbarer Status: `status/`
- Runtime-Persistenz: später ausschließlich über die dafür definierte Storage-Schicht

Temporäre lokale Dateien, Browserprofile, Logs und Build-Artefakte gehören nicht in das Repository.
